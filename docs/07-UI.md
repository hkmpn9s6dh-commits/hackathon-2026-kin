# 07 · UI — 第一眼凭什么停下来

> 闸 A 的一部分：风格预设、尺子、一个记忆点、主屏规格。写于 2026-11-14 05:20。

## 1. 风格预设：**印刷家谱页**（printed pedigree）

不是暗色节点图。图数据库的演示默认长相是「深色背景 + 一堆发光圆点 + 连线」，十张里有九张长这样，评委一晚看二十张，第六张之后就分不清谁是谁。所以这里反过来：

- **纸**：`#f2eada`，暖米色，不是白。整屏只有这一块底色，没有卡片、没有阴影、没有圆角。
- **墨**：`#211d18`，近黑偏暖。所有文字和细线用它。
- **朱**：`#a02d1e`，全屏唯一的高饱和色。它只用来做一件事——把答案画出来。
- **字**：Newsreader（显示用，有光学尺寸，正文窄而挺），JetBrains Mono（日期、标签、Cypher）。

三色、两字体、零装饰。约束越少，那一根红线越响。

## 2. 记忆点

**名字坐在细线上，像家谱书里那样；婚姻是一道双线，不是箭头。**

具体：每个人没有圆点、没有方框，只有一条 120px 宽的发丝线，名字浮在线上面 13px，生卒年在下面 21px（等宽、加宽字距、小号）。夫妻之间用 **双横线** 连起来——这是谱系图的国际惯例，一看就知道是婚配，不是「朋友」也不是「同组」。

**放弃的做法**：力导向图（节点乱飞、每次刷新都不一样、没法比较）、树状缩进（婚姻放不进去）、卡片式人物（一屏放 16 张卡片就成了一堵墙）。

## 3. 布局为什么必须是「生成」的不是「手摆」的

家谱是行 + 列的结构，不是通用图。所以 `layout.ts` 走的是一条确定性的流水线：

1. **代数**：从没有父母的人出发，孩子 = 父母代数 + 1（最长路径，24 轮松弛保证收敛）。
2. **婚入的人跟随配偶**：威尔玛在这张图里没有父母，她的代数由丈夫决定——否则她会掉到第 0 行去。
3. **块**：同一行里的夫妻合成一个块（并查集）。**一个人有两个配偶时，他必须站在两人中间**，否则第二条婚姻线会横穿第一任的名字（这是第一版真实出现的 bug，现在有单测守着）。
4. **排序**：块按父母的重心（barycentre）排，两轮。
5. **居中**：逐行把子代块往父母中点挪，挪完再解决重叠（同一行最小间距 = 一列）。

没有随机、没有迭代退火：同一份数据每次画出来完全一样。评委截图对比、我自己回归，都靠这个。

## 4. 主屏规格（1440×900）

| 区 | 尺寸 | 内容 |
| --- | --- | --- |
| 报头 | 高 84，左右 40 | `Kin` 40px + 一句副题；右侧三个按钮 |
| 图 | 剩下列（约 1068 宽） | 家谱 SVG，按宽度等比缩放并垂直居中；左下角一行斜体提示 |
| 面板 | 372 宽，左一条发丝线 | 由上到下：问句框（下划线式，不是输入框）→ 答案卡 → Cypher 折叠 → 花名册 |

**答案卡的层级**：小号等宽大写的人名对（`ADA VELL → THEO LIND`）→ 30px 的正句（`Theo Lind is Ada Vell's second cousin.`）→ 15px 的解释（各自上溯几代、在哪位祖先汇合、共几个祖先）→ 两枚小标签（`3 UP · 3 DOWN`、`2 SHARED ANCESTORS`）→ 关系链（共同祖先用朱色加粗）→ 反向说法（`Which makes Ada Theo's …`）。

先给结论，再给依据，最后给可核对的路径。评委扫一眼就够，想较真也够。

## 5. 尺子（闸 D 用）

见 `08-GATE-D.md`。结论先写在这里：**这场是首届，没有往届得奖作可当尺子**；Devpost 上的同类作品缩略图只有 333×222，拿来和我方 1440×900 的整屏混排是不公平的尺子（AME-1331 已经吃过一次「尺子口径不对」的亏）。所以闸 D 现在**未过**，且不是「再磨一磨界面」能解决的，缺的是尺子本身。

## 6. 量测（卫生，不判过线）

`node scripts/measure-ui.mjs` → `proof/ui/report.md`：

- 图上的名字 17px、日期 9.5px、答案 30px、解释 15px、问句框 17px，全部在门槛之上；
- 墨/纸对比 14.0:1，次要文字 10.6:1；
- 无横向溢出；花名册点按高度 26px。

这些只证明「不难受」，不证明「好看」。好看由闸 D 判，闸 D 现在缺尺子。

## 7. 第二版（2026-11-14 上午，用户反馈后）

用户两条原话：「右侧重叠情况比较明显」「目前的整体结构和功能，还是非常单薄」「整体的 UI，还可以打磨或者重新构思一下 目前不够 优雅大方精致美观」。

### 7.1 重叠的根因（不是靠调间距糊上去的）

右侧是一列 flex 容器，子项默认 `flex-shrink: 1`。答案卡一长，浏览器不是让面板滚动，而是**把每个子项压扁**，压扁后文字溢出自己的盒子，于是盖到下一块上。截图里「Which makes…」压在「THE CHART」上就是这个。

修法只有一条：**面板里除了索引，任何一块都不许收缩**（`flex: 0 0 auto`），由索引吸收剩余高度并在内部滚动（`flex: 1 1 auto; min-height: 0`）。这样面板高度永远等于可视高度，不需要滚动，也不会重叠。索引另设 172px 下限：窗口太矮时面板整体滚动，而不是把它压成 0。

### 7.2 功能加厚（回应「单薄」）

| 新增 | 为什么 |
| --- | --- |
| **点一个名字，索引变成「所有人的关系」** | 15 条同一句 Cypher，按亲疏排序，带称谓。一次点击回答 15 个问题，这是图数据库才有的手感。 |
| **答案分成上行/下行两段** | 「3 up / 3 down」不只是一行数字，它就是答案的形状。直系（有一条腿为 0）时合并成一行 `line`，不说「down: Rosa」这种废话。 |
| **单人档案** | 生卒、父母、配偶、子女，加「N 个血亲 / N 个姻亲」。 |
| **辈分序号 I–V** | 谱系图惯例；顺手把左边的空白用起来。 |
| **跑马头**（THE REGISTER ／ 1899–2014 · 5 GENERATIONS） | 印刷页的页眉，给整块图一个标题。 |
| **长称谓缩一号** | `great-great-grandmother` 在 32px 下会被连字符断成两行（`great-` / `great-grandmother`），26px 就整行了。 |

### 7.3 「优雅」是删出来的

- 按钮从方框改成**文字 + 悬停下划线**，只留一个实心主按钮；
- 徽章（`3 UP · 3 DOWN`）改成一行等宽小字，用 `·` 分隔，不再画六个小框；
- 人名索引改成**目录式点线引导**（name ······ term），比两列名单更像一本书；
- 全屏仍然只有三种颜色；朱红只出现在「答案」上——那根线、那个称谓、那两个被选中的名字。

## 8. 第三版（2026-11-14 下午，用户说「仍然太单薄」）

这一版加的不是装饰，是**别的作品不会有的东西**：

- **数据能进能出**。`Import GEDCOM` 读 5.5.1，`Export GEDCOM` 写回去，往返一致有单测。家谱工具不能只有作者自己那 16 个人。
- **规模**。九代 1089 人的合成村，导入到首帧约 1.2 秒，整图布局 11 毫秒。人数一多，图自动切成「以某人为中心的 2 代邻域」，页眉写 `SHOWING 22 OF 1089`，行号仍是绝对代数（不会因为切了子图就从 I 重新数）。
- **Report**（页眉第三项）：一张纸上给出四件人眼看不出的结论——有共同祖先的伴侣（**一条** Cypher 扫全图，不是每对查一次）、最长不断代世系、任选两三人最近的共同祖先、缺失与孤岛。三下拉「Who connects them?」是这套查询最直观的用法。
- **改与删**。单人页有 `EDIT` / `REMOVE`；删人 `DETACH DELETE`，关系不会悬空。
- **分享**。`?a=ada&b=theo` 直接落在同一对问题上。

风格上只动了两处：页眉的按钮分成「数据」与「行动」两组，中间留白；报告用同一套纸墨，没有任何弹窗式的渐变与阴影。

## 9. 第四版（2026-11-14 15:40，用户说「展示出来太单薄，一眼能看穿的寡淡」）

用户骂的是**观感**，不是功能。前三版一直在加功能，屏幕却还是「一堆人名浮在一张空纸上」。这一版只改观感，四处：

### 9.1 页面有了明暗

整屏原本全是米色，没有明暗对比，所以「寡淡」。把报头换成墨黑实底色（`#1f1b16`），字反白，`Kin.` 的句点用朱红——页面立刻有了「封面 / 内页」的关系。这是全页唯一的深色块，不铺开。

### 9.2 每个人有了形

原来一个人只有一行字和一条发丝线，看不见。现在每人头上一个 **26px 的圆章**，两字首字母，纸色填充、墨线勾边；被选中的人反白（墨底纸字），在答案路径上的人转朱红。十六个圆章让图有了「珠」，眼睛有落脚点。

### 9.3 下半张纸用来读时间

谱系图讲「谁和谁」，讲不了「谁在谁的时代活着」。图版下方加一条 **年表带**：五条世代行，每人一条按真实年份定位的寿命细线（同一年代刻度），答案里的人转朱红。它和上面的谱系共用同一批人，是同一份数据的第二种读法——顺带把底部那条空带填了。

配套：竖向世代轴线（把 I–V 串起来）、图版双线框（`inset` 双层 box-shadow）、纸面极细点纹。

### 9.4 面板与图纸对上了

答案卡开头不再是干巴巴一行大写的人名，而是 `◯AV ADA VELL ⟶ ◯TL THEO LIND`——两个小圆章，和图上的一模一样。图上的黑章、面板里的黑章，是同一对人在两处的同一张脸。

### 9.5 红线会自己长出来

`pathLength="1"` + `stroke-dasharray` + 900ms 的 `dashoffset` 动画：换一对人，红线从第一个人开始画到第二个人。`prefers-reduced-motion` 下不画，直接出现。

### 9.6 已知的取舍

- 手机（<940px）隐藏图例、按钮换行；图会缩到很小，这是谱系图在窄屏的固有代价，不做横向滚动。
- 年表带在 5 代以内好看，超过 8 代会挤成一片，届时应当只画选中路径上的人。
